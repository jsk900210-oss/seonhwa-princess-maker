# 선화공주 만들기 — MVP 이미지 자산 패키지

모바일 세로형 육성 시뮬레이션의 이미지 자산 구조와 로딩 테스트입니다.

## 현재 상태

- 완료: 9세 선화 공식 기준 전신 투명 PNG, 집 안채 아침 배경 WebP, 자산 목록, 모바일 로딩 화면, 1주 단위 순차 스케줄 선택·실행, 자동 검사 도구
- 완료: 기본·웃음·슬픔·당황·화남·피곤함 전신 6종과 대화용 얼굴 표정 4종 투명 PNG. 게임에서 캐릭터를 누르면 전신 표정 순환하며 피로 40 이상이면 피곤함 자동 적용
- 완료: 서당·장터·약방 MVP 배경 WebP 및 일정별 장소 전환
- 다음: 일정·상태·소지품 UI 아이콘과 저장·불러오기
- 원칙: 캐릭터 기준 원화 승인 전에는 성장형·표정·의상을 대량 생성하지 않음

## MVP 제작 순서

1. `seonhwa-age09-base.png` — 9세 기본 전신, 투명 배경, 1024×1536
2. 표정 4종 — 기본/웃음/슬픔/당황, 동일 캔버스·동일 정렬
3. 레이어 3종 — 몸통, 기본 의상, 머리·장신구 (필요할 때만 분리)
4. 집 안채 배경 — 아침 1080×1920 WebP (완료)
5. 일정 카드용 장소 배경 — 서당, 장터, 약방
6. 최소 UI — 상태창, 일정 카드, 대화창, 버튼

## 폴더 규칙

```text
assets/
  characters/seonhwa/age-09/
    base/          기본 전신
    expressions/   표정 파생
    layers/        교체 가능한 의상·장신구
  backgrounds/home/
  ui/
  reference/       출처·고증 메모 (게임에서 직접 로드하지 않음)
src/               모바일 로딩 테스트
tools/             자산 검사 도구
```

## 실행

이 폴더에서 간단한 로컬 서버를 실행한 뒤 `src/index.html`을 엽니다.

```powershell
python -m http.server 8000
```

브라우저 주소: `http://localhost:8000/src/`

## 현재 조작

- `일정`에서는 현재 주차 하나만 열리고 월요일부터 일요일까지 7일을 편성합니다.
- 하단의 교육·아르바이트·휴식을 누르면 다음 빈 날짜에 자동 배치되며, 채운 날짜를 누르면 삭제됩니다.
- 7일을 모두 채워 한 주를 실행하면 다음 주가 열리고, 4주를 완료하면 다음 달 1주로 이동합니다.
- 비용·수입·능력치·피로는 7일 결과를 합산해 반영됩니다.
- 주간 실행 시 월요일부터 일요일까지 장소가 전환되며 공부·절하기·걷기·쓸기·채집·호흡 모션이 순서대로 재생됩니다.
- 재생 중에는 일정별 배경 위에 목재·창호·단청색을 사용한 한국풍 중앙 무대가 나타나고, 축소된 선화 캐릭터가 무대 안에서 움직입니다.
- 활동 버튼에는 선화 얼굴과 책·산가지·보자기·빗자루·약초·방석을 조합한 전용 초상 아이콘 7종이 표시됩니다.
- 상태 화면은 기초 능력, 예술·기술, 무예·전문, 인품·상태의 20개 가로 게이지로 표시됩니다.
- 우측 상단 메뉴에서 진행 저장·불러오기·처음부터 시작하기를 사용할 수 있습니다. 저장 데이터는 브라우저 로컬 저장소에 보관됩니다.

검사:

```powershell
python tools/verify_assets.py
```

## 고증 기준

- 국가유산포털 조선왕조 의궤: 왕실 행사·건축·생활상 시각 자료
- 국가유산포털 전통건축 및 국가유산 검색
- 국립민속박물관 한국민속대백과사전 「한국의식주생활사전: 의생활」

각 이미지의 구체적 참고 URL과 판단은 `assets/reference/sources.md`에 기록합니다. 생성 이미지는 공공기관 원본을 복제한 것이 아니라, 검증 자료를 고증 기준으로 삼은 독자 제작물입니다.
