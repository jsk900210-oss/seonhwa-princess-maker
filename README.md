## 수정 및 GitHub 기록 원칙

앞으로 크고 작은 수정마다 아래 절차를 반드시 지킨다.

1. 디버깅 버전을 증가시킨다. 형식은 `v주.부.패치-debug`이다.
2. 이 README의 `현재 디버깅 버전`에 수정 내용과 검사 결과를 기록한다.
3. `CHANGELOG.md`에는 사용자에게 보이는 최종 변경을 기록한다.
4. 실패·재시도·복구 판단은 `UPDATE_ATTEMPTS.md`에 기록한다.
5. 관련 자동 검사와 실제 브라우저 로딩을 확인한다.
6. 커밋 제목을 `v버전: 변경 요약` 형식으로 작성하고 동일 버전 Git 태그를 만든다.
7. GitHub 원격 저장소에 커밋과 태그를 함께 푸시한다.

검증에 실패한 상태는 안정 버전으로 표시하지 않으며, README에 미완료 사유를 남긴다.

## 현재 조작

- `일정`에서는 현재 주차 하나만 열리고 월요일부터 일요일까지 7일을 편성합니다.
- 하단의 교육·아르바이트·휴식을 누르면 다음 빈 날짜에 자동 배치되며, 채운 날짜를 누르면 삭제됩니다.
- 7일을 모두 채워 한 주를 실행하면 다음 주가 열리고, 4주를 완료하면 다음 달 1주로 이동합니다.
- 비용·수입·능력치·피로는 7일 결과를 합산해 반영됩니다.
- 주간 실행 시 월요일부터 일요일까지 장소가 전환되며 공부·절하기·걷기·쓸기·채집·호흡 모션이 순서대로 재생됩니다.
- 재생 중에는 일정별 배경 위에 목재·창호·단청색을 사용한 한국풍 중앙 무대가 나타나고, 축소된 선화 캐릭터가 무대 안에서 움직입니다.
- 활동 버튼에는 선화 얼굴과 책·산가지·보자기·빗자루·약초·방석을 조합한 전용 초상 아이콘 7종이 표시됩니다.
- 상태 화면은 기초 능력, 예술·기술, 무예·전문, 인품·상태의 20개 가로 게이지로 표시됩니다.
- 우측 상단 메뉴에서 진행 저장·불러오기·처음부터 시작하기를 사용할 수 있습니다. 저장 데이터는 브라우저 로컬 저장소에 보관됩니다.

검사:

```powershell
python tools/verify_assets.py
```
