# 선화 이미지 제작 디렉토리

새 이미지 제작용 빈 폴더입니다. 삭제한 기존 이미지를 복원하지 않습니다.

- home/연령: 홈 화면 전신 이미지
- dialogue/연령: 대화용 상반신 이미지와 표정
- schedule/일정/연령: 일정용 전신과 모션
- schedule/common/연령: 공용 걷기·달리기·인사

연령 구간: age-09-12, age-13-15, age-16-17, age-18-plus.
일정 내부 동작은 제작 시 read/, turn-page/, mistake/ 등으로 구분하고 frame-01.png부터 번호를 붙입니다.
걷기·달리기는 left/, right/ 등 방향을 구분합니다.

손과 함께 움직이는 책·붓·호미·쟁반 등 기본 소품은 해당 선화 프레임에 포함합니다.
고정 책상·배경·NPC는 이 폴더와 분리합니다.
개별 투명 PNG로 저장하고 얼굴·색상·크기·접지 기준 및 프레임 연속성을 검수합니다.
.gitkeep은 GitHub에서 빈 폴더 구조를 유지하기 위한 파일이며 이미지가 아닙니다.
