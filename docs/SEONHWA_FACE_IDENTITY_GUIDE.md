# 선화 얼굴 동일성 기준

선화의 얼굴은 `assets/characters/seonhwa/identity/`의 연령별 기준 이미지로 고정한다.

- 9세: 둥근 볼과 아동 비율을 유지한다.
- 13세: 얼굴 길이만 조금 성장시키고 이목구비의 간격은 유지한다.
- 16세: 턱선을 자연스럽게 정돈하되 눈·코·입 형태는 바꾸지 않는다.
- 18세: 성인 얼굴로 성숙시키되 다른 사람처럼 재설계하지 않는다.

표정 이미지에서는 눈꺼풀, 눈썹 각도, 입 모양과 볼의 긴장만 변경한다. 눈 사이 간격, 코의 폭과 위치, 입술 윤곽, 얼굴형의 기본 골격은 변경하지 않는다. 의상 이미지에서는 헤어스타일과 의상만 변경할 수 있으며, 얼굴은 해당 연령 기준을 그대로 사용한다.

새 의상·표정·바캉스 일러스트를 생성할 때는 반드시 해당 연령 기준 이미지를 정체성 참조 이미지로 함께 사용한다.
