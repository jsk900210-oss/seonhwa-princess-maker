## 사용자 최종 요청

1. 달력은 기존보다 크게 보이게 한다.
2. 달력은 쯔꾸르 프레임 최상단에 붙이고, 캐릭터나 스테이터스를 가리지 않는다.
3. `착실히 일한 일수`와 `수입` 결과는 쯔꾸르 프레임 내부에 띄우지 않는다.
4. 페이즈 결과는 쯔꾸르 프레임 바깥 하단 공간에 간결하게 표시한다.
5. 오래된 CSS 실험 규칙이 최종 배치를 다시 덮어쓰지 못하게 한다.
