## 확인 사항

- 모든 일정 캡션에 현재 착용 의상명이 표시된다.
- 활동 스프라이트는 착용 한복에 맞춘 팔레트가 적용된다.
- 조연이 있는 활동은 주인공과 조연을 분리 배치하며 표시 영역이 겹치지 않는다.
- 식사 스프라이트는 152×152px 표시 영역 안에서 잘리지 않는다.
- 390px 모바일 화면에서 `scrollWidth`와 `clientWidth`가 모두 390px로 측정됐다.
