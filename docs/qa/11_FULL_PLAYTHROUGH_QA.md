# 9세~19세 자동 플레이 재검사

기준 버전: `v0.62.51-debug`
검사일: 2026-08-16

## 1차 검사 — 달력·성장·엔딩 경계

- 1990년 1월 1일부터 12월 31일까지 가능한 생일 365개를 모두 검사했습니다.
- 각 생일은 9세 생일부터 시작해 19세 마지막 생일 다음 날에 정확히 종료됩니다.
- 마지막 주는 `daysUntilEnding()` 결과만큼만 실행되어 종료일 뒤 활동이 능력치·은전에 추가 적용되지 않습니다.
- 10세부터 19세까지의 생일 경계를 각각 한 번씩 통과합니다.
- 최종 성장 나이는 모든 생일에서 19세로 유지됩니다.

검사 명령:

```powershell
node tools/test_calendar_progression.mjs
```

검사 결과:

```text
PASS: 1990년 생일 365개 전체 검사
PASS: 마지막 일정 길이 7~7일, 종료일 초과 활동 0건
PASS: 10~19세 생일 이벤트 경계 및 최종 19세 종료 검증
```

## 3차 검사 — 저잣거리·바캉스 복귀

- 저장 기록에 7일 일정이 이미 채워져 있어도 일정 화면을 열면 실행 확인창이 다시 나타납니다.
- 저잣거리는 `집으로 돌아가기`가 눌릴 때까지 다음 날 진행을 대기합니다.
- 주막·한복점에서 저잣거리 선택 화면으로 돌아갈 수 있고, 저잣거리 종료 뒤 다음 일정과 기본 음악이 이어집니다.
- 바캉스 시작 전에 남아 있던 주문·선택·미리보기 UI를 닫습니다.
- 바캉스 일러스트와 인연 대화를 터치로 끝낸 뒤 다음 일정으로 복귀합니다.

검사 명령:

```powershell
node tools/test_special_schedule_flow.mjs
```

## 4차 검사 — 저장 슬롯·비정상 종료 복구

- 최대 5개의 육성 기록만 사용합니다.
- 진행 중에는 최신 자동저장과 현재 육성 슬롯을 함께 갱신합니다.
- 5초 주기, 앱이 숨겨질 때, 페이지를 벗어나기 직전에 보호 저장합니다.
- 이름·날짜가 없거나 이미 엔딩이 끝난 기록은 이어하기 후보에서 제외합니다.
- 잘못된 저장 시각은 가장 오래된 값으로 처리해 최신 정상 기록 선택을 방해하지 않습니다.
- 이전 기록에 1~5 범위를 벗어난 슬롯 번호가 있으면 기존 일치 슬롯 또는 빈 슬롯으로 복구합니다.

## 5차 검사 — 바캉스 음악·계절 효과

- 9·13·16·18세 사계절 주제곡 16개가 모두 존재하며 실제 파일 크기가 정상입니다.
- 19세는 성인용 18세 음악 세트를 사용합니다.
- 모바일 자동재생 차단을 피하도록 바캉스 진입 즉시 해당 계절 음악을 재생한 뒤 0.9초 동안 자연스럽게 키웁니다.

- 동작 줄이기 환경에서는 카메라 이동은 멈추되 정적인 계절 아티팩트는 유지됩니다.
