# 쯔꾸르 캐릭터·NPC 전체 검수 보고서

- 대상: v2 일정 20종 + 글읽기·셈하기·예절 교육 3종
- 교육 3종: 선화와 훈장 NPC도 동일한 96×96px 표시 상자·바닥선에 포함
- 공통 표시 상자: 선화 96×96px, NPC 96×96px
- 바닥 기준: 각 이미지의 하단을 동일 바닥선에 정렬
- 헤어 계약: 낮은 한쪽 땋은 머리의 승인된 `schedule-actions/v2` 프레임만 허용, 구형 경로는 실패
- 방향 계약: 선화 이미지 좌우 반전 금지. 이동은 위치만 변경
- 춤: 부채를 직접 든 단일 선화 프레임만 사용하며 별도 소품 레이어는 금지

## 자동 검수

`node tools/test_full_schedule_tukkur_audit.mjs`는 다음을 강제합니다.

1. 20개 일정 명세가 모두 검사 대상에 존재하는지
2. 선화와 NPC의 최종 CSS가 `#activityStage` ID 우선순위로 96px을 보장하는지
3. 구형 일정 프레임 또는 좌우 반전 규칙이 실행 경로에 없는지
4. 사용 중인 v2 선화 3프레임 세트가 모두 존재하는지

Claude 검수 시에는 이 보고서와 `tools/test_full_schedule_tukkur_audit.mjs`의 조건, 그리고 각 일정의 실화면에서 인물·NPC·소품이 서로 침범하지 않는지를 함께 확인하면 됩니다.
