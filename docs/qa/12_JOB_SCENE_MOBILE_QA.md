# 신규 아르바이트 9종 모바일 배치 검사

검사 버전: `v0.62.61-debug`

## 검사 대상

- 농가 일손 돕기, 아이 돌보기, 주방 보조
- 목공소, 베틀방, 기와·흙벽
- 약방 견습, 나루터, 상점 판매

## 결과

- 9종 모두 준비 → 작업 → 마무리의 서로 다른 3개 프레임을 사용합니다.
- 캐릭터 머리·발·도구가 실행창 바깥으로 잘리지 않습니다.
- 작업대, 베틀, 화덕, 짐, 판매대와 캐릭터 기준선이 배경 원근에 맞습니다.
- 큰 도구가 포함된 베틀·약방·판매 프레임은 별도의 모바일 크기를 적용했습니다.
- 농가와 아이 돌보기처럼 동물이거나 조연이 프레임에 포함된 경우에도 주인공과 겹치지 않습니다.
