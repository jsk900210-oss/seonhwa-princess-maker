## v0.63.97-debug 추가 규정

- 손에 쥐어야 자연스러운 검·마법봉은 선화 전용 3프레임에 결합하고, 별도 부유 소품을 중복 표시하지 않습니다.
- 성인 NPC는 `npcScale: 1`과 146px 표시 규격을 사용하며, 아동 NPC만 명세의 전용 축소 배율을 허용합니다.
- 글읽기 훈장은 left 67%에 배치해 외곽 잘림 없이 선화와 대화 거리를 유지합니다.

이 팩은 현재 `src/app.js`에 등록된 잠금 교육 8종과 잠금 아르바이트 14종을 모두 포함합니다.

## 절대 규칙
- 선화 캐릭터 PNG는 이 팩에 포함하지 않습니다.
- 선화는 `manifest.json > existingHeroFrames`의 기존 `schedule-actions/*-pixel-1~3.png`만 사용합니다.
- NPC·소품·실패·효과만 별도 레이어로 합성합니다.
- 모든 3프레임은 `1 → 2 → 3 → 1 → 2 → 3`으로 반복합니다.
- `[0,1,2,1,0]` 왕복 재생은 사용하지 않습니다.

## 포함 교육 8종
회화, 악기, 전통 춤, 검술, 술법, 향토 음식, 무예, 경전 심화

## 포함 아르바이트 14종
농가 일손, 아이 돌보기, 주방 보조, 목공소, 베틀방, 기와·흙벽, 약방, 주막, 바느질, 서책 필사, 나루터, 상점 판매, 상단 장부, 학동 가르치기

## 각 일정 폴더
- `background-overlay/`: 기존 배경 위에 얹는 투명 장식층
- `npc/`: 선화와 구분되는 역할별 NPC 3프레임
- `success-a/`: 성공 패턴 A 3프레임
- `success-b/`: 성공 패턴 B 3프레임
- `fail-a/`: 가벼운 실패 3프레임
- `fail-b/`: 큰 실패 또는 사고 3프레임

## 적용 순서
1. 기존 배경
2. background-overlay
3. 뒤쪽 소품
4. NPC
5. 기존 선화
6. 성공/실패 패턴
7. 효과

## 좌표
각 일정의 권장 `left / bottom / scale` 값은 `manifest.json > schedules > <id> > placement`에 있습니다.
현재 주방 화면에서 선화·주모·가마솥이 왼쪽에 겹쳤던 문제를 피하도록, 주모는 오른쪽 72%, 선화는 42%, 작업 소품은 중앙 52%를 기준으로 분리했습니다.

## 클로드 작업 지시
- 이 팩을 프로젝트 루트에 압축 해제합니다.
- `manifest.json`을 읽어 현재 일정 렌더러에 공통 레이어 컨테이너를 추가합니다.
- 일정별로 존재하는 파일만 로드합니다.
- 각 자산의 경로가 HTTP 200으로 로드되는지 확인합니다.
- 모바일 세로 화면에서 바닥선을 맞추고, manifest 좌표를 초기값으로 사용합니다.
- 검수 전에는 `main`에 병합하지 않습니다.

# v0.64.02-debug 실제 3프레임 작업 규정

- 일정 동작은 정지 PNG를 흔들어 대신하지 않는다. 손·팔·상체 또는 다리 자세가 다른 1→2→3 프레임을 사용한다.

- 아이돌보기 선화는 아이 쪽을 바라보고, 이불은 아이 몸 앞의 동일 바닥선에 둔다.
