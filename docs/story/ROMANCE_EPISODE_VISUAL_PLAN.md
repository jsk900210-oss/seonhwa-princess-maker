# 인연 에피소드 시각 기준표

최종 갱신: 2026-08-16  
기준 버전: `v0.62.88-debug`

이 문서는 5명의 인연 후보가 1~5회 만남에서 어떤 장소, 의상, 표정, 포즈, 카메라로 보여야 하는지 정리한 기준표다.
현재는 코드와 분리된 준비 문서이며, 이후 이미지 제작과 장면 연결 시 이 표를 기준으로 사용한다.

## 공통 규칙

- 얼굴은 현재 인연 시스템의 연령별 베이스를 따른다.
- 전신 기준은 13 / 16 / 19세 폼을 유지하되, 에피소드마다 의상과 포즈는 달라진다.
- 각 장면은 `장소 + 의상 + 포즈 + 표정 + 카메라 구도`를 한 세트로 본다.
- 바캉스와 데이트는 이 표를 우선 참고하고, 명절 이벤트는 같은 인물이라도 별도의 특수 포즈를 사용한다.

## 도윤

1. 흩어진 화살
- 장소: 활터
- 의상: 젊은 무관 도포와 팔이 좁은 활동복
- 포즈: 화살을 함께 줍고 몸을 살짝 숙인 자세
- 표정: 경계하다가 안심한 표정
- 카메라: 반측면 허리샷

2. 마당의 충돌
- 장소: 집 마당
- 의상: 소매를 걷은 일손복과 묶은 띠
- 포즈: 빗자루를 들고 서로 비켜 서는 동작
- 표정: 머쓱하게 웃는 표정
- 카메라: 정면 약간 아래에서 본 전신

3. 산길의 발자국
- 장소: 산길 입구
- 의상: 짧게 묶은 여행 복장과 장갑
- 포즈: 발자국을 짚으며 손바닥으로 흙을 살피는 동작
- 표정: 집중한 표정
- 카메라: 대각선 원경 전신

4. 강가의 약속
- 장소: 강가 산책로
- 의상: 바람에 잘 흩날리지 않는 담백한 나들이 옷
- 포즈: 강을 향해 천천히 걷는 옆모습
- 표정: 차분히 말하는 표정
- 카메라: 옆구도 허리 위 샷

5. 나란히 선 활터
- 장소: 활터
- 의상: 정돈된 무관 차림과 장식 없는 허리띠
- 포즈: 활을 내려놓고 나란히 서서 쉬는 동작
- 표정: 약속을 건네는 미소
- 카메라: 가까운 2인 반신샷

## 서진

1. 바뀐 서책
- 장소: 서당 서가
- 의상: 깨끗한 서생 옷과 얇은 겹깃
- 포즈: 책장을 두 손으로 바로잡는 동작
- 표정: 예의 바른 첫인사
- 카메라: 책장 옆 중경샷

2. 먹이 번진 글
- 장소: 서책상
- 의상: 소매가 넓지 않은 필사복
- 포즈: 번진 종이를 가볍게 들어 올리는 동작
- 표정: 난처하지만 다정한 미소
- 카메라: 상단 사선 구도

3. 어려운 물음
- 장소: 서당 마루
- 의상: 차분한 서생 차림과 매듭 장식
- 포즈: 주판과 책을 번갈아 가리키는 동작
- 표정: 설명에 집중한 표정
- 카메라: 탁자 너머 반신샷

4. 정자의 시구
- 장소: 정자
- 의상: 가벼운 나들이 도포와 고운 허리끈
- 포즈: 난간에 기대어 풍경을 바라보는 동작
- 표정: 조용히 읊조리는 표정
- 카메라: 옆모습 원경

5. 남겨 둔 책갈피
- 장소: 서책방
- 의상: 책갈피가 잘 보이는 단정한 학자복
- 포즈: 책갈피를 끼워 두고 돌아서는 동작
- 표정: 미소를 숨긴 눈빛
- 카메라: 책상 위 클로즈업

## 연우

1. 날아간 화첩
- 장소: 꽃밭 길
- 의상: 붓집이 달린 바람 잘 타는 작업복
- 포즈: 날아간 화첩을 두 손으로 받아내는 동작
- 표정: 놀라다 안도하는 표정
- 카메라: 전신 사선샷

2. 마르지 않은 색
- 장소: 화실
- 의상: 색이 묻어도 자연스러운 화공 작업복
- 포즈: 물감 접시를 옆으로 건네는 동작
- 표정: 차분한 집중 표정
- 카메라: 책상 옆 중근경

3. 장단과 붓끝
- 장소: 연습 마루
- 의상: 움직임이 넉넉한 공연복
- 포즈: 장단에 맞춰 붓끝을 크게 돌리는 동작
- 표정: 흥이 오른 표정
- 카메라: 움직임이 보이는 전신샷

4. 달빛 초상
- 장소: 달빛 정원
- 의상: 달빛 반사가 잘 어울리는 은은한 나들이옷
- 포즈: 무릎을 세우고 앉아 멀리 바라보는 동작
- 표정: 그윽하게 미소 짓는 표정
- 카메라: 측면 반신샷

5. 비워 둔 자리
- 장소: 야외 화판 앞
- 의상: 바람에 살짝 흔들리는 가벼운 외출복
- 포즈: 화폭의 빈 자리를 손끝으로 짚는 동작
- 표정: 함께 기다리는 눈빛
- 카메라: 화판 너머 3/4샷

## 태겸

1. 잘못 묶인 짐표
- 장소: 나루터
- 의상: 짐 나르기 좋은 단단한 상단 복식
- 포즈: 짐표를 바로 고쳐 묶는 동작
- 표정: 재빠르게 판단하는 표정
- 카메라: 허리 높이 전신샷

2. 한 냥의 흥정
- 장소: 저잣거리
- 의상: 장사꾼 느낌의 깔끔한 상단 옷
- 포즈: 손가락으로 값을 세며 흥정하는 동작
- 표정: 장난기 있는 미소
- 카메라: 맞은편 대치 구도

3. 비에 젖은 장부
- 장소: 상단 장부방
- 의상: 소매를 접은 계산용 복식
- 포즈: 젖은 장부를 닦고 숫자를 세는 동작
- 표정: 집중하고 책임감 있는 표정
- 카메라: 책상 위 대각선샷

4. 나루의 저녁
- 장소: 나루터 저녁
- 의상: 바람을 덜 타는 두꺼운 외출복
- 포즈: 짐을 내려놓고 차를 건네는 동작
- 표정: 조용히 웃는 표정
- 카메라: 노을을 뒤로한 반신샷

5. 함께 갈 장길
- 장소: 큰 장 입구
- 의상: 화사하지만 실용적인 상단 외출복
- 포즈: 앞장서며 손을 내미는 동작
- 표정: 기대에 찬 미소
- 카메라: 길을 함께 보는 2인 샷

## 현

1. 평범한 윷놀이
- 장소: 마당
- 의상: 신분을 드러내지 않는 평복
- 포즈: 윷을 던진 뒤 고개를 기울이는 동작
- 표정: 웃음을 참는 표정
- 카메라: 작은 탁자 위 반신샷

2. 낯선 호위
- 장소: 어두운 길목
- 의상: 움직임이 편한 호위복과 짧은 망토
- 포즈: 앞을 가로막고 몸을 낮추는 동작
- 표정: 경계하는 날카로운 눈빛
- 카메라: 측면 전신샷

3. 궁 밖의 소문
- 장소: 저잣거리
- 의상: 평민처럼 보이는 단정한 외출복
- 포즈: 사람들 틈에서 뒤돌아 듣는 동작
- 표정: 말을 아끼는 차분한 표정
- 카메라: 군중 사이 3/4샷

4. 등불 아래 진심
- 장소: 등불 거리
- 의상: 등불빛을 받으면 은근히 빛나는 나들이복
- 포즈: 등불을 손으로 가리며 서 있는 동작
- 표정: 고백 직전의 흔들리는 표정
- 카메라: 등불 뒤 역광 반신샷

5. 다시 만날 문
- 장소: 큰 문 앞
- 의상: 신분을 밝힐 준비가 된 단정한 정장형 복식
- 포즈: 문 쪽으로 한 걸음 내딛는 동작
- 표정: 결심한 듯한 표정
- 카메라: 정면 대칭 구도
