# 《선화공주 만들기》 인연 이벤트 시스템

## 기본 구조

- 인연 후보: 도윤, 서진, 연우, 태겸, 현
- 각 인물은 서로 다른 장소와 활동에서 시작하는 고유 만남 5회를 가진다.
- 14~15세에는 친분과 신뢰 중심으로 진행하며, 5회 만남을 채우면 데이트와 바캉스 동행이 열린다.
- 고유 만남은 한 번만 발생하고 완료 플래그를 저장한다.
- 같은 인물을 5회 이상 만나면 `데이트 신청`과 `함께 바캉스`가 열린다.
- 만남 횟수와 호감도는 별도로 관리한다. 5회 만남만으로 연애 엔딩이 확정되지는 않는다.

## 5회 만남 단계

1. 첫 만남: 인물과 장소를 소개한다.
2. 우연한 재회: 성격과 능력을 확인한다.
3. 갈등 또는 협력: 함께 문제를 해결한다.
4. 개인 사정: 약점이나 비밀을 알게 된다.
5. 관계 선택: 친구로 남거나 더 가까워질 가능성을 연다.

5회차 완료 후 상태는 `데이트 가능`이 된다. 연애 관계 확정은 이후 데이트 선택과 호감도 조건으로 결정한다.

## 설날·추석 인연 이벤트

게임 달력에서는 설날을 `봄 1주`, 추석을 `가을 3주`의 명절 주간으로 사용한다.

### 설날

- 명절 주간 홈 또는 저잣거리에서 발생한다.
- 세배, 복주머니, 떡국, 윷놀이, 새해 소원 중 인물 설정에 맞는 장면을 사용한다.
- 이미 만난 인물만 등장할 수 있다.
- 아직 다음 고유 만남 조건을 채우지 못했다면 명절 특별 대사와 호감도만 지급한다.
- 다음 고유 만남 조건을 충족했다면 설날 장면이 정식 만남 1회로 진행될 수 있다.

### 추석

- 명절 주간 저잣거리, 강가, 정자 또는 마을 잔치에서 발생한다.
- 송편, 달맞이, 풍물놀이, 성묘, 등불 장면을 인물별로 다르게 사용한다.
- 이미 만난 인물만 등장할 수 있다.
- 다음 고유 만남 조건을 충족한 경우 추석 장면이 정식 만남 1회로 진행될 수 있다.

### 중복 방지

- 같은 인물의 같은 명절 장면은 육성 기록당 한 번만 만남 횟수에 포함한다.
- 이후 같은 명절에 다시 만나면 짧은 재회 대사와 소량의 호감도만 지급한다.
- 한 명절 주간에는 인연 후보 한 명의 주요 이벤트만 발생한다.

## 데이트 신청

### 해금 조건

- 해당 인물 고유 만남 5회 완료
- 해당 인물 호감도 기준 충족
- 결별 또는 관계 잠금 플래그가 없을 것

### 이용 방식

- 홈 화면의 `인연` 메뉴에서 데이트 가능한 상대를 선택한다.
- 데이트는 다음 주 일정 7칸 중 하루를 사용한다.
- 장소는 인물별 기본 데이트 장소와 계절 장소 중에서 선택한다.
- 데이트 결과는 호감도, 스트레스, 감수성, 평판 등에 반영한다.
- 거절당하거나 조건이 부족한 경우 일정은 소비하지 않는다.

## 함께 바캉스

바캉스를 일정에 넣었을 때 다음 선택 화면을 표시한다.

1. 혼자 간다
2. 함께 간다

`함께 간다`를 누르면 5회 이상 만난 데이트 가능 인물만 목록에 표시한다.

### 혼자 간다

- 기존 계절 바캉스 일러스트를 감상한다.
- 새로운 인물을 우연히 만날 가능성이 있다.
- 수집도감 카드와 스트레스 회복을 적용한다.

### 함께 간다

- 선택한 인물과 계절별 동반 장면을 재생한다.
- 다른 인연 후보는 무작위로 등장하지 않는다.
- 해당 인물 호감도가 상승하고 전용 대화·추억 플래그를 저장한다.
- 이미 획득한 계절 수집 카드는 중복 지급하지 않는다.

## 인물별 명절·데이트 성격

| 인물 | 설날 | 추석 | 대표 데이트 장소 |
|---|---|---|---|
| 도윤 | 활쏘기 내기와 새해 호신부 | 야간 순찰 중 달맞이 | 활터, 산길, 강가 |
| 서진 | 새해 시구와 서책 선물 | 정자에서 달을 보며 시 짓기 | 서책방, 정자, 서당 뜰 |
| 연우 | 복주머니에 작은 그림 그리기 | 잔치 풍경과 달빛 초상화 | 화실, 꽃밭, 축제 거리 |
| 태겸 | 세뱃돈 흥정과 떡국 나눔 | 상단 송편 장사와 마을 기부 | 저잣거리, 상단 창고, 나루 |
| 현 | 평민 차림으로 윷놀이 | 신분을 숨긴 채 등불 구경 | 사찰, 궁 밖 정원, 눈길 |

## 저장 데이터

인물별로 다음 값을 저장한다.

- `meetCount`: 완료한 고유 만남 수, 최대 5
- `affinity`: 호감도
- `completedEpisodes`: 완료한 고유 에피소드 ID 목록
- `holidayFlags`: 설날·추석 주요 이벤트 완료 기록
- `dateUnlocked`: 데이트 해금 여부
- `vacationMemories`: 함께 다녀온 계절 목록
- `relationship`: 지인, 친구, 특별한 인연, 연인, 결별

## 구현 순서

1. 인물별 고유 만남 5회 데이터 작성
2. 설날·추석 주간 판정과 명절 이벤트 연결
3. 홈 화면 인연 메뉴와 만남 횟수 표시
4. 데이트 신청과 일정 하루 소비
5. 바캉스의 `혼자 간다 / 함께 간다` 선택 화면
6. 동반 바캉스 대사와 이미지 제작
7. 호감도·관계 상태를 엔딩 판정에 연결
