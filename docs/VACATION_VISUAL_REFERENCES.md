## 게임에 가져온 시각 요소

- 넓고 풍성한 치마폭과 촬영 시 크게 흐르는 실루엣
- 위아래 색이 부드럽게 이어지는 그라데이션
- 완전히 덮이는 속치마 위에 겹쳐지는 갈래형 겉치마
- 짧고 정돈된 저고리, 계절꽃 자수, 노리개와 작은 머리 장식
- 굵은 컬을 넣은 뒤 느슨하게 땋은 머리, 반묶음, 낮은 땋은 쪽머리와 자연스러운 잔머리

## 사용 원칙

위 페이지는 현대 창작 한복의 촬영 분위기와 실루엣을 파악하기 위한 시각 참고다. 사진이나 특정 의상을 그대로 복제하지 않으며, 게임 원화는 색·자수·장식·구도를 새로 설계한다. 역사 복식의 근거는 별도의 `COSTUME_REFERENCE_SOURCES.md`에 기록한 국내 공공기관·박물관 자료만 사용한다.
