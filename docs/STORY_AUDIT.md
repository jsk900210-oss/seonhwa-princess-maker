# 서사·진행·엔딩 정합성 검토

## 결론

세계관과 핵심 서사는 유지한다. 다만 아래 규칙은 게임 진행이 막히거나 엔딩이 잘못 선택되는 문제를 막기 위해 수정한다.

## 확정 수정

1. **1990년은 사주 시드만 사용**: 본편에 1999~2009년을 표시하지 않는다. 화면은 `9세 · 봄 1주`처럼 가상 왕조의 계절 달력으로 표시한다.
2. **생일 건너뛰기 방지**: 7일 일정이 생일을 지나면 해당 생일을 처리한 뒤 남은 날짜를 진행한다. 18세 생일 다음 날에만 엔딩 판정한다.
3. **엔딩 우선순위 재배치**: 발각·파탄·건강 위기는 직업 엔딩보다 먼저 검사한다. 그렇지 않으면 높은 능력치가 파국을 부당하게 덮는다.
4. **능력치 범위 통일**: 장기 성장 능력치는 0~999, 관계·memory·exposure는 0~100, truth는 0~12로 확정한다. UI 막대는 각각의 최대값으로 환산한다.
5. **프롤로그 방울 소리 수정**: S12에서 방울이 실제로 울리면 18세 최초 울림과 충돌한다. S12 음악의 낮은 종음은 상징적 배경음일 뿐, 극중 방울은 S1~S11과 마찬가지로 무음이다.
6. **요절 표현 수정**: 9~18세 아동 육성 게임에서 건강 수치 하나로 갑작스러운 사망을 확정하지 않는다. `꺼진 등불`은 중병으로 육성이 중단되는 열린 결말이며, 사전 경고와 회복 기회를 반드시 제공한다.

## 엔딩 판정 우선순위

1. 위기 엔딩: 발각 → 관계 파탄 → 중병
2. 초자연 특수: 강으로 돌아가다
3. 정체 선택: 핏줄을 잇다 → 진실을 알고 남다
4. 핵심 가족: 딸이 되다
5. 관계·거래 엔딩
6. 직업 엔딩
7. 정체 부분 발견
8. 기본 보장: 물여울의 딸

## 추가 보완이 필요한 서사

- 선화가 발견 당시 방울에 새겨진 글자를 읽지 못하는 이유: 열병·기억상실뿐 아니라 고문자라 일반인은 바로 읽기 어렵다고 설정.
- 서진이 9년 동안 추격을 피하는 이유: 무하촌의 폐쇄성, 변포교의 지연 보고, 청 나그네의 흔적 제거를 단계적으로 제시.
- 한참판이 즉시 제거하지 않는 이유: 선화의 생존을 확신하지 못하며 공개 수색 시 과거 방화가 드러날 위험이 있다고 명시.
- ‘신관·무녀의 핏줄’은 혈통 우월성이 아니라 잃어버린 역사와 책임의 문제로 다룬다.

## 진행 안전 규칙

- 정체 단서를 하나도 얻지 않아도 기본 엔딩 가능.
- 필수 사건은 일정 활동 하나에만 묶지 않고 나이 도달 시 대체 경로 제공.
- 돈 부족으로 교육이 막혀도 무료 활동과 노동으로 회복 가능.
- 피로·건강 위험은 최소 두 번 경고 후 중단 엔딩 판정.
- 관계 수치가 낮아도 18세까지 시간 진행 자체는 가능.
