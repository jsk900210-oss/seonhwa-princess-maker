# 직업 엔딩 일러스트 고증 기준

## 공통 원칙

- 시대 배경은 조선 후기의 복식·생활상을 기준으로 한다.
- 얼굴 참조는 선화의 정체성에만 사용하며, 기존 분홍 한복을 직업 의상으로 복제하지 않는다.
- 실재 복식이 확인되는 왕실·군직·궁중무용은 해당 유물과 의궤 계통의 구조를 우선한다.
- 여성의 동일 관직 복식이 확인되지 않는 가상 직업은 남성 관복을 임의로 여성화하지 않고 저고리·치마·장옷·배자 등 확인 가능한 여성 생활복을 사용한다.
- 마법·신수는 빛과 비인간 존재로만 표현하고, 복식에는 서양 판타지 요소를 넣지 않는다.

## 직업별 적용

| 직업 | 적용한 복식·생활 자료 계통 |
| --- | --- |
| 여왕 | 조선 후기 왕실 여성의 당의, 저고리, 치마, 비녀 |
| 왕실 학사·마을 훈장 | 흰 저고리, 짙은 치마, 장옷·배자의 여성 생활복과 서책·문방구 |
| 도화서 화원·명화가 | 여성 생활복, 먹·안료·벼루·붓 등 회화 도구 |
| 궁중 무희 | 치마·저고리·쾌자·전대·전립·한삼으로 전승된 궁중/교방 무복 |
| 명인 재주꾼 | 조선 후기 여성 연희자의 저고리·치마·쾌자와 가야금 |
| 대장군 | 구군복의 동다리·전복·전대·전립 구조를 사용한 대체역사 표현 |
| 무예 교관 | 여성 생활복과 배자, 속바지·행전 계통의 실용적 구성 |
| 왕실 술법사·수호자 | 검증된 여성 생활복. 초자연 요소는 소품과 빛에만 한정 |
| 비밀 탐험가 | 저고리·치마·장옷, 보자기, 죽장, 지등의 생활·여행 도구 |
| 거상 | 비교적 고운 저고리·치마·배자와 장부·산가지·저울·상품 |
| 의상 명인 | 침선비/침선 생활 도구와 검소한 작업복, 삼베 앞치마 |
| 수라간 대령숙수 | 면 저고리·치마, 삼베 앞치마, 팔 고정끈과 수라간 조리 도구 |
| 의원 | 의녀 계통을 참고한 절제된 청색 생활복과 약장·약연·저울 |
| 외교관 | 여성 외출복인 장옷과 보자기·두루마리·노정도 |
| 평온한 삶 | 무명·모시 생활복, 앞치마, 소반·다기·텃밭 |
