# 서사 구현 정리

## 채택한 핵심 설정

- 가상 왕조의 무하촌과 여울강
- 보호자 서진과 기억을 잃은 선화
- 소리 없는 방울, 강 건너 불빛, 백로와 물의 노래
- 정체를 밝히지 않아도 완결되는 기본 엔딩 `물여울의 딸`
- 9~18세 성장, 관계·노출도·기억·진실 조각 기반 분기

## 기존 구현과 조정한 부분

- 1990년 생년월일은 세계관의 실제 연도가 아니라 사주 시드로 사용한다.
- 내부 계산에는 날짜를 유지하되 본편 화면은 가상 왕조의 나이·계절 중심으로 바꿀 예정이다.
- 현재 프롤로그는 12장면 데이터와 대사를 모두 적용했다.
- 원화는 아직 3장뿐이므로 장면별로 재사용한다. 다음 자산 제작은 S1, S2, S3, S4, S6, S8, S11, S12 순서다.
