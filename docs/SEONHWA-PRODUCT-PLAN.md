# 선화 키우기 제품 전환 기준

목표: 프린세스메이커 2의 월간 육성·경제·평판·모험·다중 결말 구조를 참고하되 선화의 인물, 한복, 신수, 한국 명절과 독자적인 대사·미술을 유지한다. 원작 수치를 동일하게 재현했다고 주장하지 않는다.

## 다음 구현 순서와 완료 조건

1. 월간 일정: 기존 저장을 백업해 변환하고 윤년 2월, 30일·31일 월, 월중 불러오기를 검증한다. 휴가·명절도 편성 기간만 소비하며 실행 기록과 실제 날짜가 일치해야 한다.
2. 생활 관리: 식단·생활비·질병·치료를 실제 일별 실행과 월말 장부에 연결한다. 표시된 잔액과 결산이 일치해야 한다.
3. 경연·탐험: 네 분야 경쟁과 네 지역 탐험을 플레이 가능하게 만들고 획득 보상·평판이 저장되어야 한다.
4. 인맥·결말: 교류 결과와 육성 기록이 엔딩 판정에 반영되는 테스트를 만든다.
5. 제품 검수: 새 게임부터 졸업까지 완주, 저장·불러오기, 모바일 대화 배치, 누락 이미지, 음향, 디버그 버전과 배포 버전 확인.

## 이번 구현의 선화 전용 수치

성공·무난은 분야별 +1, 완벽은 +2를 적용한다. 힘겨움·실수에는 새 기술·명성 보너스가 없다. 아버지 친밀도 0~100에 따라 새해 양육비는 2,500~7,500냥이다. 원작 공식이 아닌 선화용 초안이며 장기 플레이 후 조정한다.
