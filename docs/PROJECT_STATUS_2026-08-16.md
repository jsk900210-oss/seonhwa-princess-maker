# 《선화공주 만들기》 진행 현황 정리

작성일: 2026-08-16
기준 브랜치: `main`

## 지금까지 반영된 핵심 방향

- 모바일 우선 UI 기준으로 일정/대화/상점/인연 연출을 정리했다.
- 프롤로그, 신수 소개, 바캉스, 저잣거리, 집 휴식, 아르바이트, 교육의 표현을 프메식 흐름으로 다듬고 있다.
- 인연 시스템은 5회 만남, 설날/추석 특별 만남, 데이트 신청, 바캉스 동행까지 이어지는 구조로 잡았다.
- 바캉스는 계절별 수집, 동행, 오버레이 대화, 상황별 연출을 중심으로 확장 중이다.
- 의상 시스템은 구매 즉시 적용, 중복 구매 방지, 연령대별 노출 차이, 동작별 의상 반영을 목표로 정리했다.

## 현재 작업 중인 주요 정리 항목

### 1. 인연 시스템

- 남자 인연 후보 5명 구성
  - 도윤: 젊은 무관
  - 서진: 선비
  - 연우: 화공
  - 태겸: 상단 후계자
  - 현: 정체를 숨긴 왕자
- 각 인연은 우연한 만남 → 재회 → 오해/관심 → 다음 만남 약속 → 여운 순서로 진행
- 인연 대화는 오버레이 형식으로 진행
- 남자 주인공은 얼굴/반신 오버레이로 등장
- 여자 주인공은 선택형 대사 중심으로 처리

### 2. 바캉스

- 계절별 수집 카드 확장
- 현대 느낌 / 전통 느낌을 분리해 관리
- 시즌별로 다른 주제곡과 조금씩 움직이는 효과를 적용
- 동행 시 연인 오버레이 대화가 뜨는 구조로 정리

### 3. 신수 시스템

- 프메2의 큐브처럼 신수가 홈 화면에서 대화와 안내를 맡는 구조
- 신수 대화 결과에 따라 능력치 변화
- 신수 선택 전 소개 영상이 먼저 나오고, 터치로 다음으로 넘어가는 흐름

### 4. 교육 / 아르바이트 / 휴식

- 교육은 성장에 따라 해금되는 항목을 확장
- 아르바이트는 전용 장면과 숙련 단계가 존재
- 휴식은 집에서 차 마시기 / 잠자기처럼 단순하고 명확한 연출로 정리
- 던전은 휴식 탭의 추가 콘텐츠 후보로 유지

### 5. 상점 / 의상

- 방문상점은 랜덤 방문 NPC 방식으로 정리
- 구매한 의상은 즉시 적용
- 중복 구매 방지
- 의상별 연령대 차이와 체형 반영을 추가 검토

## 아직 우선순위가 높은 이슈

1. 스케줄 실행 시 캐릭터 깨짐 / 눈 검은색 / 얼굴 일관성 문제
2. 집 휴식, 아이돌보기, 주방보조, 장터심부름 등의 이미지 잘림 수정
3. 인연 대화 오버레이가 프메식으로 더 자연스럽게 연결되도록 정리
4. 바캉스 / 신수 소개 영상의 연출을 채팅 흐름과 맞추기
5. 모바일 화면에서 UI 겹침 문제를 다시 점검
6. 19세 엔딩, 30개 엔딩 포맷, 직업/인연/능력치 분기 정리
