# 바캉스 복식 제작 기준 자료

바캉스 일러스트의 복식은 특정 유물을 그대로 복제하지 않고, 아래 국내 공공기관 자료에서 확인되는 구조·선·색·장신구를 바탕으로 게임용 창작 의상으로 재구성한다.

## 공통 한복 구조

- 국립민속박물관 한국문화상자 「여자 한복」: 여성 한복의 기본 구성인 치마·저고리, 고름, 노리개, 운혜를 기준으로 삼는다.
  - https://nfm.go.kr/k-box/ui/hanbok/female.do
- 국립민속박물관 어린이박물관 「전통의상」: 넓은 치마폭, 자연스러운 주름, 치마허리 끈, 깃·동정·배래·색동 구조를 참고한다.
  - https://www.nfm.go.kr/kids/user/content.do?pageId=PAGE_000000000000050

## 신라 계열 장면

- 국립중앙박물관 「신라인의 삶을 읽어 내는 텍스트, 토우」: 신라 토우에 남은 춤·노동·생활 동작과 고대 복식 실루엣을 참고한다.
  - https://www.museum.go.kr/MUSEUM/contents/M0501000000.do?relicRecommendId=166326&schM=view
- 국립중앙박물관 전시도록 「영원한 여정, 특별한 동행」의 ‘토우로 본 고대 복식’: 고대 활동복의 간결한 선과 움직임을 참고한다.
  - https://www.museum.go.kr/MUSEUM/contents/M0208000000.do?arcId=19256&catCustomType=report&catId=118&schM=view

## 고려 계열 장면

- 국립중앙박물관 소장 보물 「고려불화 수월관음도」: 고려 불화의 섬세한 겹옷, 길게 흐르는 선, 주홍·녹청·금색 계열 배색을 참고한다.
  - https://www.museum.go.kr/MUSEUM/contents/M0502000000.do?relicId=35853303&schM=view

## 갈래치마 적용 원칙

- 역사 유물의 정확한 명칭으로 단정하지 않고 `활동형 겹치마` 또는 `갈래치마풍 창작 의상`으로 표기한다.
- 넓은 전통 치마폭과 잔주름을 유지하면서, 겉치마 앞판이 좌우로 갈라져 안치마가 보이는 이중 구조로만 재해석한다.
- 현대 미니스커트, 과도한 노출, 시대 불명의 판타지 갑옷 요소는 사용하지 않는다.
