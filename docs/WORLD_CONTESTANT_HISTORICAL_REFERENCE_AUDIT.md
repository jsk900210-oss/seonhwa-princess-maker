# 세계 참가자 복식·머리 고증 감사표

## 적용 원칙

- 기준 시대는 후기 조선과 겹치는 18세기 후반–19세기 전반으로 제한한다.
- 의상과 머리 모양은 같은 시대·문화권의 박물관 실물 또는 초상 자료가 함께 확인된 경우에만 최종 자산으로 승인한다.
- 현대식 국가 이미지, 관광 상품, 코스프레 사진, 생성형 이미지, 출처가 불명확한 Pinterest·블로그 이미지는 근거 자료로 사용하지 않는다.
- 자료에서 확인되지 않는 장신구·머리 장식·문양은 임의로 추가하지 않는다.
- 9–12세 참가자는 성인 초상의 과도한 화장·신분 표식을 그대로 복제하지 않고, 의복 구조와 머리 결발 방식만 연령에 맞게 단순화한다.
- 생성 이미지는 투명 배경, 전신, 발끝 포함, 단일 인물이어야 하며 알파 채널과 흰 테두리를 별도로 검사한다.

## 자산 승인 절차

1. 의상 실물과 인물 초상의 날짜·문화권을 확인한다.
2. 프롬프트에 소장기관·작품명·연대·확인 가능한 구조만 기입한다.
3. 생성 후 머리 실루엣, 가르마, 결발 위치, 장신구 수, 칼라·소매·치마 구조를 기준 자료와 대조한다.
4. 불일치 자산은 프로젝트에 연결하지 않고 재생성한다.
5. 승인된 캐릭터만 무작위 참가자 풀과 우승 확대 장면에 함께 등록한다.
