## 이번 반영

- 약초 뽑기 실패에 양손을 머리 위로 드는 놀람 프레임을 추가하고 앞으로 넘어지는 동작 앞에 연결했습니다.
- 활성 `schedule-layers-v2` 매니페스트의 125개 프레임 묶음이 실제 서로 다른 이미지인지 자동 검사합니다.
- 원본 시트·크로마 제작본·배경을 런타임 투명 레이어로 오인하던 자산 감사 규칙을 정정했습니다.
- 농가 닭 추격은 한 페이즈 동안 진행 방향을 유지하며 선화와 닭이 같은 방향으로 이동합니다.
- 아이 돌보기는 아이와 선화 간격을 고정하고 좌우 전환 중 캐릭터가 도는 듯 보이는 보간을 제거했습니다.
- 전체 자동 검사 39개와 1,538개 이미지 자산 감사가 통과합니다.

- 인연 후보 5명의 1~5회 만남을 장소·의상·표정·포즈·카메라 기준표로 정리하고 코드와 문서에 같은 값을 반영했습니다.
- 새 키우기 시작 자금을 50,000냥으로 변경하고 한복점에 전체 의상 18벌의 수량을 표시했습니다.
- 아르바이트 보수를 `60~90냥` 범위로 상향해 교육비와의 비율을 맞췄습니다.
- 교육·아르바이트·실패의 스트레스 증가량을 낮춰 주간 누적 속도를 완화했습니다.
- 집에서 휴식의 스트레스 감소량을 `-12`로 상향했습니다.
- 한복점에서 고급 의상은 황금색, 현재 나이에 맞아 열린 일반 의상은 녹색으로 구분했습니다.
- 바캉스 스트레스 감소량을 `-25`로 조정하고 실패 없음 규칙을 유지했습니다.
- 전 연령 공용 고급 의상 5종, 9·13·16·18세별 투명 전신 PNG 20장을 추가했습니다.
- 한복점 구매, 옷장 착용, 성장 단계별 이미지 전환을 연결했습니다.
- 활동 포즈는 현재 의상별 대표 색상까지 반영되며, 고급 자수·장식이 정확히 맞는 포즈별 프레임은 다음 이미지 스프린트에서 제작합니다.
- 공개 테스트: `https://jsk900210-oss.github.io/seonhwa-princess-maker/`

## 핵심 결정사항

- 스케줄은 월간이 아니라 7일 단위로 편성합니다.
- 스케줄 활동은 쯔꾸르풍 2D 무대에서 캐릭터와 배경을 분리해 표현합니다.
- 모든 일반 스테이터스 최대치는 999, 피로·스트레스 최대치는 100입니다.
- 홈 화면의 의상 변경은 제거하고 옷장에서만 갈아입습니다.
- 바캉스는 계절별 일러스트 한 장을 사용하며 수집도감에 기록합니다.
- 일반 활동에서는 기본 BGM을 유지하고 바캉스·저잣거리에서는 전용 음악을 사용합니다.
- 저장 데이터 내보내기·가져오기 UI는 사용하지 않고 브라우저 자동저장과 5개 인연 기록을 사용합니다.
